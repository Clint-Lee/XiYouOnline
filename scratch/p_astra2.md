# 任务：《汉风西游》对白趣味性与幽默性优化方案（只出方案，不写代码）

## 项目背景
原生 JS 单机西游 RPG，主角设定：威灵显赫大将军（玩家），因在水帘洞护住花果山幼猴、抗旨不杀而被玉帝削去仙籍、封存记忆，贬落凡尘双叉岭，被猎户刘伯钦所救。此后护送玄奘西行。
同伴：孙悟空（记得前世恩情）、猪八戒（前身天蓬元帅，醉酒调戏嫦娥被贬）、沙僧（前身卷帘大将，失手打碎琉璃盏）。

## 当前对白基调（已确立，不可破坏）
1. **幽默来自人物性格与处境反应，不来自玩梗**。现有成功范例：
   - 猪八戒："这两箱行李，老猪挑得肩膀都快磨成馒头了。你是卷帘大将，挑担总该比卷帘容易吧？"
   - 沙僧查抄行李："这盒写着'大圣防风假睫毛'……大师兄，你眼睛怕烟，便拿金丝做挡风帘？这倒真是一门神通。"
   - 刘伯钦："短剑和皮靴拿着，别光脚去跟荆棘讲道理。"
   - 太白金星："南天门闸机都快挤坏了，蹭饭的倒比持帖的还多！"
   - 悟空："俺在这儿等了五百年，连山顶的草都比俺会走路！"
2. **绝对红线**：不拿受害者遭遇开玩笑。白骨精三打中，村姑/老妪/老翁是被害者的画皮，师父的悔悟、无辜者的死、被掳者的家书——这些都保持严肃。奎木狼囚禁百花羞十三年同理。
3. 单次对白尽量只交代一个行动目标，避免信息堆叠。
4. 已删除现代俚语与品牌梗（如"报销""账房"曾清理过一轮，但"工部若问起来，可别把飞剑写成针灸报销"这类轻度办公室幽默仍保留）。

## 请输出（不要写代码，只给方案）
