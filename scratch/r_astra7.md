## 结论

**采用 8 阶段闭环；牛魔王不新增 Boss 机制；章节核心是“借扇失败后，悟空必须从取巧转向承担责任”。**

- **叙事落点**：救百姓不等于铁扇公主必须原谅悟空；最终达成的是救灾合作，不是恩怨清零。
- **交互落点**：假扇试验、识破变化、牛魔王战斗、断绝火根各承担一种功能，不堆叠新系统。
- **工程落点**：复用阶段五处表、线索选项、战后对白与奖励接口；地图保留连通骨架，满包不阻塞灭火事实。
- **规模建议**：约 32–36 个对白节点，最多 2 处轻幽默，不扩展独立摩云洞地图。

## 2. 核心张力设计

### 张力推进

**百姓急需救火 → 铁扇公主拒借有因 → 悟空强取遭假扇 → 再度变化遭反骗 → 战斗终止夺扇冲突 → 公开担责后重新借扇。**

| 关键问题 | 设计处理 | 必须避免 |
|---|---|---|
| 铁扇公主为什么恨 | 她明确区分“红孩儿去了观音处”与“母亲愿意接受这一结果”；她失去了与孩子共同生活、亲自过问其去向的机会，悟空却上门要求帮助 | 用“孩子得了正果，你还不知足”驳倒她；把她写成只会撒泼的障碍物 |
| 她是否可以不借 | 承认宝扇属于她，怨恨也真实；同时呈现百姓并不是这场恩怨的参与者 | 把私人拒绝与无辜者受灾混为一谈，或让灾民集体跪求、道德围攻她 |
| 悟空如何变化 | 腹中逼扇不搞身体笑料；假扇之后第一次认识到“拿到东西不等于解决事情”；被反骗后，不再追加第三次骗术 | 连续靠机变碾压所有人，最后只需接受奖赏 |
| 火源责任何时揭明 | 土地在假扇失败后说明落砖成山；悟空不能再把火灾当作与自己无关的路障 | 把火灾归罪于铁扇公主；把意外起火写成悟空故意纵火 |
| 悟空承担什么 | 最终当面承认火源与自己的经历有关，也承认腹中逼迫、变化欺骗损害信任；亲自断根并归还真扇 | 以“我也是为了大家”取消道歉；承诺直接把红孩儿带回来 |
| 最终靠什么合作 | 铁扇公主决定不让百姓继续替旧怨受苦；悟空停止强取并承担善后，双方明确借用、归还关系 | “打服了，所以交扇”；以借扇交换牛魔王免罚 |
| 和解到什么程度 | **同意救灾，不等于原谅；可以收束冲突，不必成为朋友** | 全家突然热情送行，红孩儿之怨凭一句话消失 |

### 假扇事件：失败属于故事，不属于玩家操作

| 环节 | 玩家获得的信息与控制 |
|---|---|
| 领取 | UI 只写“待验证的芭蕉扇”，不宣布“真扇到手”，不发阶段成功奖励误导玩家 |
| 试验 | 卷轴明确要求在隔离小火口试验，附近无灾民、粮仓或房屋 |
| 观察 | 扇后小火口火势反增；土地说明正常效用应是火势减弱，给出足够判断依据 |
| 线索选项 | 固定选择“停扇，验其真伪”为正确行动；错选返回同一观察步骤，不实际加扇、不伤人、不扣资源 |
| 收束 | 悟空承担被欺骗的后果；不让角色责怪玩家“为何相信她”，不要求重复跑路或刷战斗 |

变化牛魔王与反被变化八戒欺骗，采用**短事件串**，不做“猜哪个八戒是真的”的第二套谜题，也不显示真假分支让玩家承担必然失败。

### 牛魔王、哪吒与托塔天王的时机

| 角色 | 介入时机 | 叙事职责 |
|---|---|---|
| 牛魔王 | 借扇前已有旧交与家庭关系铺垫；第二次借扇后亲自变化夺回 | 让悟空受到同一种骗术的反制；其立场是反对妻子再次受骗，但携扇离开会使救灾停摆 |
| 哪吒 | 对质升级、牛魔王准备带扇脱身时到场 | 与悟空共同制止争斗扩散；助阵通过开战对白体现，不引入临时队友新系统 |
| 托塔天王 | 与哪吒同时到场，战后负责约束牛魔王 | 终止追击与再次夺扇，不主持“命令铁扇公主交出宝物” |
| 铁扇公主 | 战后仍保留完整发言与拒绝权 | 最终决定借扇的主体，不是胜利结算中的掉落来源 |

## 4. 是否需要 Boss 机制

### 判断：不新增

| 判断维度 | 结论 |
|---|---|
| 本章真正难点 | 借用关系、旧怨与责任，不是破解牛魔王的战斗状态 |
| 既有系统负担 | 本章已有假扇验证、两次变化、战后重新借扇、灭火领奖等状态链，不宜再增加专属战斗状态 |
| 连续两章未新增机制 | 不是必须补机制的理由；章节差异应服务于体验，不服务于轮换指标 |
| 与既有样板区分 | 不新增蓄力周期，不新增实时换甲，不换名称复刻旧机制 |
| 战斗的功能 | 终止牛魔王携扇脱身与冲突升级，为重新谈判创造条件；不能代替铁扇公主的决定 |

### 牛魔王战斗的最低充分方案

- 单 Boss，复用现有伤害、命中、治疗和技能结算。
- 普通攻击负责稳定压力，既有单体重击负责集火压力，既有群体伤害负责恢复压力；具体技能以已存在实现为准。
- 不新增护送、限时、夺扇 QTE、专属资源条或临时队友系统。
- 难度以同等级常规配置可胜为目标，不强制特定角色或消耗品。
- 失败停留在 `huoyan_confront_bull`，允许休整重试；不丢扇、不降阶段、不重播整段骗扇事件。
- 胜利先持久化阶段，再调用 `scheduleStoryDialogue`；错过战后对白仍可直接找铁扇公主继续。

**专属 `hh_*` 状态挂载：无。** 哪吒助阵不修改玩家永久属性，也不偷偷附加新的战斗胜负条件。

## 5. 幽默位与禁笑区

| 位置 | 处理 | 来源与限制 |
|---|---|---|
| 初次抵达休整地，尚未讲述具体受灾经历前 | 可留 1 处：八戒把行李换了三次肩，发现哪边都烫，只好老实放到遮阴处 | 来自八戒怕热与身体反应；一句收束，不引发师兄弟连续逗嘴 |
| 灭火完成、确认百姓安全之后 | 可留 1 处：八戒先试了试石凳，确认不烫，才放心坐下 | 与开场呼应；不抢铁扇公主告别或灾民谢意的情绪位置 |

### 禁笑区

- 灾民饮水、粮食、居所与生计受损。
- 铁扇公主谈红孩儿，以及悟空回应母子分离。
- 腹中逼扇：不做疼痛、求饶或身体部位笑料。
- 假扇使火势增大：不做“玩家被骗了”的嘲讽反馈。
- 土地揭明火源、悟空认责。
- 牛魔王战败：不羞辱其形貌、婚姻或家庭。
- 四十九扇断根及百姓确认火灭。

如对白过密，**优先删去第二处幽默，不以笑点充当章节节拍器**。

| 11 | 牛魔王仅在正确阶段可开战；战斗中重复交互不重复开战；失败不推进，胜利只推进一次且不直接发真扇或章节奖励 |
| 12 | 牛魔王战斗不挂载 `hh_cart_state`、`hh_armor_state` 或新增专属状态，现有两种机制的回归断言保持通过 |
| 13 | 战后对白同时校验 mapId 与 storyPhase；离图或阶段变化后不弹过期对白；对白取消不阻塞后续 NPC 交互 |
| 14 | `huoyan_fire_extinguished` 单向持久化；四十九扇以一次可完成、可跳过表现的事件呈现，重复交互、重载不重播灾害或重新索扇 |
| 15 | 所有奖励物品先存在于 `items.js`；奖励走统一接口，成功与 `already_claimed` 不重复给道具、经验、银两或 bonuses |
| 16 | `inventory_full` 后保留火根台领奖入口与正确卷轴、小地图提示；灭火事实不回滚，腾包重试或重载后仍能进入终态 |

## 7. 实施顺序

| 顺序 | 工作包 | 必须同批完成 | 验收门槛 |
|---:|---|---|---|
| 1 | 现状核对与基线冻结 | 核对现有火焰山实体、坐标单位、入口、出口、存档结构；运行测试基线 | 2166/2166，形成实际 ID 与候选 ID 对照 |
| 2 | 阶段与持久化契约 | **8 阶段定义、推进守卫、阶段五处表、开幕初始化、灭火事实必须同批** | 所有阶段可解析，刷新与回图不丢进度；定义好目标实体契约 |
| 3 | 地图与实体 | **碰撞改造、实体站位、交互格、传送落点、BFS 断言必须同批** | 熄火前后、各实体可见状态下均连通，目标可达 |
| 4 | 借扇到反骗的叙事链 | **对白 key、action 路由、固定线索选项、阶段推进与事件重入处理必须同批** | 从入图可完整推进至牛魔王对质，无假选项、无重复剧情物品 |
| 5 | 牛魔王战斗及重新议借 | **开战入口、胜败回调、战后调度、铁扇公主接续入口必须同批** | 失败可重试；离图不弹错对白；胜利不等于强制交扇 |
| 6 | 灭火、归扇与奖励闭环 | **`items.js` 定义、奖励调用、满包重试、熄火表现、终态及出口判断必须同批** | 满包也能完成灭火；奖励可恢复且仅发一次；最终出口状态正确 |
| 7 | 全量回归与文本审查 | 新增断言、旧基线、关键手动路径、人物称谓及幽默密度审查 | 原 2166 条全部通过，新增用例全绿，无剧情软锁 |

第 2、3 步可在同一开发分支内分步实现，但**不得交付“阶段目标已上线、实体尚不存在”的中间版本**。

最终手动验收至少走四条路径：

1. 正常完整通关。
2. 假扇连续错答、牛魔王战败后重试。
3. 战胜后立即离图，返回继续借扇。
4. 满包灭火、重载、腾包领奖，再次点击确认不重复奖励。

**最终取舍：把复杂度用于“阶段可靠、动机成立、失败不罚玩家”，而不是再做一套牛魔王状态机。**
