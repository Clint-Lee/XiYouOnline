当前工作区没有可供审查的项目文件，地图实测项将明确标为待验，坐标方案不冒充已验证结果。
## 结论

| 决策项 | 推荐方案 |
|---|---|
| 阶段规模 | **7 个阶段，含 `chedi_cleared` 终态**；前三仙不各自拆成长任务链 |
| 核心体验 | **解救受役僧人 → 王廷立约 → 祈雨 → 坐禅辨物 → 三仙决战 → 复法领关文** |
| 三场斗法 | 前两场用有线索的对白选项，第三场用现有三敌首领战；不新增小游戏系统 |
| Boss 机制 | **不新增第三类机制**；用三名首领的现有技能分工、集火顺序形成变化 |
| 奖励闭环 | 独立领取阶段；满包不推进，已领可修复推进，奖励与对白分离 |
| 最大风险 | 地图实测缺失、跨阶段战后对白被丢弃、重复战斗回调、满包后领取入口消失 |

**核验边界：当前 `/workspace` 未发现项目文件，不能提供真实地图测量结果或声称测试已通过。以下地图数值区分“已知要求”和“建议布局理论值”，实施前必须补实测。**

原著处理上，建议明确为“三轮玩法压缩”，而非宣称原著只有三项斗法；虎力斩首赌胜、鹿力剖腹、羊力油锅的情节，也不应写成虎力因求雨失败直接被斩。

## 1. 阶段链设计

### 阶段总表

下表“可见 NPC”指**剧情交互 NPC**；普通居民不受此表约束。三仙的场景 NPC 与战斗敌人使用不同 ID。

| 阶段名 | 进入条件 | 可见剧情 NPC | 唯一主线目标 | 任务卷轴要点 | 退出触发 |

| `chedi_rain` | 王廷立约完成 | 僧人、国王、三仙 | `npc_chedi_tiger` | 验证求雨本领；先看天候，再依序验风、云、雷、雨 | 祈雨对白最终成功动作，进入 `chedi_discern` |
| `chedi_discern` | 第一轮胜出 | 僧人、国王、三仙 | `npc_chedi_deer` | 坐禅定心，隔板辨物；识破鹿力借干扰与暗示改判 | 辨物对白最终成功动作，进入 `chedi_final_trial` |
| `chedi_final_trial` | 第二轮胜出 | 僧人、国王、三仙 | `npc_chedi_sheep` | 三仙拒不认输；破除邪术，保护在场众人 | 三仙战斗胜利回调，进入 `chedi_reward_pending` |
| `chedi_reward_pending` | 决战胜利已落阶段 | 获释僧人、国王；三仙隐藏 | `npc_chedi_king` | 确认停止迫害、恢复寺院，领取谢礼及西行关文 | 奖励返回 `success`；或核实 `already_claimed` 后修复推进，进入终态 |
| `chedi_cleared` | 奖励领取完成、关文通行资格落定 | 获释僧人、国王 | **无本章活动目标** | 本章已完成；显示明确的西行去向或“后续章节待开放” | 不再推进本章；仅允许合法地图移动 |

**目标唯一性定义：六个活动阶段恰好一个主线目标，终态零个。**不要为了满足“唯一”而在终态留下永久指向国王的假任务。

### 五处映射必须同批落实

| 设施 | 设计要求 |
|---|---|
| `phaseWeights` | 七阶段按上述顺序严格递增；与前后章节保持现有权重规则 |
| `isNpcVisibleInStoryPhase` | 决战前保留三仙；胜利进入领奖阶段即隐藏，不等领取奖励才隐藏 |
| `MAIN_QUEST_TARGETS` | 每个活动阶段只指向表中一个实体 |
| `getOrdealAndQuestInfo` | 卷轴动作、目标名、失败提示与实际可执行行为一致 |
| `minimap.getCurrentQuestTarget` | 与主线表解析出相同实体；终态同步清空 |

国王在其他阶段可以有环境对白，但**不能提前开放领奖动作**。

### 对白与奖励约束

建议对白键固定为：

- `chedi_monk_appeal`
- `chedi_royal_terms`
- `chedi_rain_trial`
- `chedi_discern_trial`
- `chedi_final_challenge`
- `chedi_victory`
- `chedi_reward`
- `chedi_after_clear`

失败与重试优先放在现有对白的 `steps/options` 分支，不额外制造剧情阶段。

| 情况 | 必须行为 |
|---|---|
| 决战胜利 | 先落 `chedi_reward_pending`，再在目标地图、目标阶段上下文中调度 `chedi_victory` |
| 战后对白因离图失效 | 不回滚胜利；回城后仍可直接找国王领取 |
| 正常领奖 | 统一使用 `claimStoryReward`；建议唯一键 `chedi_ch14_clear` |
| `inventory_full` | 保留 `chedi_reward_pending`、国王领取选项及小地图指向；不得另行提前发经验或银两 |
| `already_claimed` | 不重复发奖；仅在合法领奖阶段确认同一奖励键已领后补完终态 |
| 关文 | 推荐作为终态对应的剧情通行资格，不额外占背包格；若项目已有关文道具规范，则遵循原规范 |

## 3. 三场斗法设计

采用“**验术 → 辨伪 → 破邪**”三轮压缩，避免把六七项原著法术逐项做成系统。

| 场次 | 表现机制 | 玩家操作 | 失败反馈 | 成功反馈 |
|---|---|---|---|---|
| 第一轮：祈雨验术，虎力主试 | `STORY_DIALOGUES` 多步选项；通过对白呈现风、云、雷、雨，不新增天气模拟或计时系统 | 阅读天候线索；选择先验风云，再验雷雨；由悟空行动、唐僧见证 | 贸然要求落雨时，提示“风云未合”，返回本轮准备步骤；不扣资源、不降阶段 | 公开完成验雨，虎力失去独占“国师神通”的依据，推进第二轮 |
| 第二轮：坐禅辨物，鹿力主试 | 坐禅作为开场叙事；隔板辨物作为带线索的对白分支 | 先稳住心神，不回应挑衅；听取物件线索，选择辨认结果 | 错答后指出遗漏的线索，返回本轮观察步骤；不随机换题、不要求原著知识 | 揭穿干扰与暗示，国王开始质疑三仙，推进终局 |
| 第三轮：邪术现形，羊力主试 | 砍头、剖腹、油锅压缩为三仙夸术及邪术败露的叙事；调用一次 `start2DBattle`，三仙同场 | 使用现有攻击、技能、治疗；决定先压制哪名首领 | 战败按现有恢复规则处理，阶段仍为 `chedi_final_trial`；只重打第三轮 | 战斗胜利后三仙现原形、邪术消散；进入领奖阶段，国王公开纠错 |

### 递进关系

| 维度 | 第一轮 | 第二轮 | 第三轮 |
|---|---|---|---|
| 玩家要求 | 读懂明确顺序 | 区分线索与干扰 | 资源管理与目标选择 |
| 冲突升级 | 质疑神通垄断 | 揭穿斗法操弄 | 三仙拒绝认输并动武 |
| 国王态度 | 偏信三仙 | 动摇、要求复验 | 承认误判并落实纠错 |
| 失败成本 | 即时重试 | 即时重试 | 仅重试当前战斗 |

前两轮正确选择必须由**当前对白线索**支持，不能做成作者知道答案、玩家只能盲猜的题。

## 4. 是否需要新 Boss 机制

### 判断：普通首领战足够，不新增第三类机制

| 理由 | 设计收益 |
|---|---|
| 三仙同场已改变单 Boss 的决策结构 | 玩家自然面对集火顺序与多源伤害 |
| 本章已有对白斗法承担差异化 | 无需再叠一套专用状态教学 |
| 避免复制时序／姿态样板 | 不做“换名字的蓄力爆发”或“三仙轮流换甲” |
| 降低接入面 | 不新增伤害修正规则、专属 buff 生命周期或复杂恢复状态 |

### 三仙分工

以下角色分工只使用**实际已存在且已验证的技能**；没有对应技能就降级为普通攻击与数值差异，不借本章补系统。

| 首领敌人 ID | 战斗分工 | 可形成的应对 |
|---|---|---|
| `enemy_chedi_tiger` | 较高直接伤害 | 优先击杀，减少持续承伤 |
| `enemy_chedi_deer` | 使用已有干扰／减益技能；无则改为稳定法术输出 | 优先清除干扰，或用已有解控／净化应对 |
| `enemy_chedi_sheep` | 使用已有恢复／防护技能；无则改为高生存低输出 | 优先打断恢复来源，或集中火力逐个击破 |

**不新增 `chedi_*` 专用 buff。**现有技能若带 buff，就复用其既有定义和清理规则。

难度不能按“三个完整单体 Boss 直接相加”配置：应控制总生命、总行动伤害与续航，让两种以上击杀顺序可行，不能把“先杀羊力”变成唯一答案。

## 5. 三条禁笑区与幽默位

## 6. Node 断言清单

建议分为 **14 组断言意图**，每组可包含多个具体断言。

| # | 断言意图 |

| 9 | **BFS 连通性**：按各阶段真实碰撞状态，从入口及返回落点可达所有必要交互位置；合法开放时可达出口，不出现只有对角贴边的假连通。 |

| 13 | **目标唯一且一致**：六个活动阶段各有且仅有一个可见、可交互目标；主线表、小地图与卷轴的目标和动作一致；终态三处同时结束本章任务。 |
