## 结论

**采用 8 阶段闭环；不新增 Boss 机制；昴日星官的两次啼鸣负责破解金光，战斗只负责制服失去金光庇护的百眼魔君。**

叙事采用“双重责任”原则：**八戒越界必须承担责任，蜘蛛精的绑缚与伤人也不能因此获得正当性。** 七女妖可以有真实诉求，但不能靠受害经历免除其加害责任。

| 决策项 | 推荐方案 |
|---|---|
| 章节结构 | 濯垢泉越界与囚困 → 解缚 → 黄花观求援遭毒 → 寻访援手 → 啼鸣破光 → 制服、救治与善后 |
| 地图组织 | 复用 `pansidong`，在同一地图划分泉边、丝洞、黄花观、寻援高处、西行出口；不新增地图系统 |
| 战斗规模 | 一场蜘蛛精遭遇战，一场普通单 Boss 战；不做七连战，不做必败战 |
| 核心解题 | 观察蛛丝线索、取得昴日援助；不以等级或重复战斗替代 |
| 章节奖励 | 集中在善后阶段领取；满包留在原阶段、原 NPC 重试 |
| 幽默预算 | 默认仅 1 处，允许全部删除 |

### 原著与本章改编的口径

有三处必须在设计文档中分清，避免把改编写成原著事实。

| 项目 | 原著口径 | 本方案口径 |
|---|---|---|
| 破解百眼魔君 | 黎山老母指点寻找毗蓝婆；毗蓝婆是昴日星官之母，以绣花针破金光 | 按本章指定，改为昴日星官两次啼鸣破光、显形，明确属于改编 |
| 毒茶受害者 | 唐僧、八戒、沙僧中毒，悟空没有被毒茶药倒 | 保留指定的悟空中毒情节，作为本章改编 |
| 黎山老母身份 | 指路者，并非化身为昴日星官之母 | 以老妇形象指路，不冒称昴日之母 |

### 必须一起定下的阶段契约

| 项目 | 设计要求 |
|---|---|
| 阶段五处表 | 八阶段在 `phaseWeights`、NPC 可见性、`MAIN_QUEST_TARGETS`、`getOrdealAndQuestInfo`、小地图目标中保持一致；终态目标统一指向西行出口 |
| 章节启动 | `_applyMapData` 必须实际调用 `ensurePansiChapterStarted()`；调用位置需保证玩家剧情状态与当前地图已就绪 |
| 幂等性 | 只从合法前置状态启动；处于任一 `pansi_*`、本章终态或后续章节时不得重置 |
| 战后对白 | **先保存胜利结果与目标阶段，再排队对白**；对白用于呈现，不承担唯一推进职责 |
| 最少补充状态 | 仅保存确实需要跨重载保留的节点事实，如“啼鸣已经完成”“善后已经完成”；不再另造一套隐藏阶段链 |
| 失败与离场 | 战败留在当前战斗阶段；离图不丢救援资格、不重复毒茶、不撤销已完成的啼鸣 |
| 物理通路 | 金光封锁表现为剧情交互限制，不改可行走网格来制造断路，继续满足地图 BFS 全连通 |
| 前后出口 | 保留返回火焰山的通路；本章西行出口只在 `pansi_cleared` 可用 |

**唯一目标不等于只能有一句对白。** 同一目标 NPC 可以顺序承接观察、交战、解救或结算，但任务卷轴与小地图不能各指向不同对象。

## 2. 濯垢泉与蜘蛛精的处理方案

### 2.1 给真实诉求，但不把她们写成无辜守泉者

| 层次 | 推荐设定 | 叙事边界 |
|---|---|---|
| 正当诉求 | 七女妖要求泉边隐私与洞居边界受到尊重，也不愿因妖身就被默认可以侵犯 | 她们拒绝窥探、驱赶越界者是正当的 |
| 主动恶行 | 她们把闯入者与过路人当作可扣押、役使、换取利益的对象，并已有捕食唐僧的打算 | 正当边界不能延伸为绑架、役使与捕食权 |
| 与百眼魔君的关系 | 本章改编为互相依赖的同盟：女妖提供蛛丝、捕获物等，百眼提供毒药与庇护 | 不能在结尾突然说“全是百眼指使”，抹去七女妖的自主选择 |
| 群体差异 | 有人主张放人止争，有人坚持扣押；至少让代表对白显露分歧 | 不增加七条支线，也不把七个人压成一个“妖艳群体” |

**关键判断：八戒受缚可以是越界的直接后果，但继续伤害他、扣押唐僧仍是加害行为。**

### 2.2 八戒变鱼段：保留事件，撤掉猎艳视角

| 环节 | 写法 | 禁止做法 |
|---|---|---|
| 唐僧先劝 | 明确说泉边有人，不应接近窥探 | 把提醒写成“怕惹麻烦” |
| 八戒越界 | 保留色心与侥幸心理：他知道不该靠近，却以变鱼“不易被发现”为借口入水戏弄 | 改成纯粹误入，替他抹掉责任 |
| 镜头处理 | 从岸上呈现水响、呵斥、蛛丝落下；女子身体和沐浴细节不进入描写重点 | 身体描写、湿衣描写、玩家窥视选项 |
| 女妖反应 | 先是明确拒绝与制止，再暴露其扣押、伤人的行为 | 把愤怒写成娇嗔，把抵抗写成调情 |
| 玩家参与 | 玩家负责制止冲突、观察蛛丝、救人 | 让玩家替八戒选择如何戏弄女子 |

线索题只考察**怎么安全解缚**，不考察“女性是不是妖，所以能否侵犯”。错答返回观察步骤，不扣资源、不退阶段、不换题。

### 2.3 八戒承担什么后果

| 后果类型 | 具体处理 |
|---|---|
| 身体后果 | 束缚勒伤与蛛毒真实存在，解缚后不能立即恢复嬉闹 |
| 责任承认 | 八戒明确承认“我先越了界”，不以“她们是妖”辩解 |
| 对他人的影响 | 承认同伴因救援陷入危险，但不能让唐僧替他承担道德责任 |
| 补救行动 | 恢复后参与安置获救者、清理危险蛛丝；在下一处边界前主动停步询问 |
| 不采用的处罚 | 不做围观羞辱、不反复嘲笑色心，不强加永久属性损失或额外缴费 |

道歉必须与问责分开：**不要求女妖接受道歉，也不因为八戒道歉就放弃追究绑架与伤人。**

### 2.4 唐僧的态度

建议以两条原则贯穿，而不是长篇训诫：

> “泉边有人，便应止步。未得应允，不可近前。”

> “你先越界，该认；她们伤人，也须止。先救人，随后说清。”

唐僧上前是制止侵犯与伤害，不是天真地要求所有人立刻和解；他受困后仍保持判断，不作为推动救援的沉默道具。

## 3. 黄花观与百眼魔君

### 3.1 毒茶必须改变局势

| 设计点 | 推荐处理 |
|---|---|
| 为什么会去 | 八戒解缚后仍有蛛毒伤势，黄花观以懂医理、能解毒的形象取得求援机会 |
| 为什么中招 | 百眼借求医之机，把“先服药茶”包装成救治；危险来自背叛援助关系，不来自角色突然愚蠢 |
| 为什么悟空没识破 | 隐去原料的毒茶不能靠看见外形判断；不要临时声称毒能无条件压制悟空的一切本领 |
| 谁承担救援 | 悟空、八戒失去行动能力；沙僧负责撤离与守护，唐僧协助照护，威灵大将负责寻援 |
| 伤害怎么呈现 | 呼吸、站立、说话和行动明显受影响；对白简短，优先交代如何维持伤者状态 |
| 压力从哪里来 | 熟悉的主力倒下、解毒方受敌人控制、求援路线必须完成，而非跳一个红色倒计时 |
| 如何避免新系统 | 用剧情受伤状态与现有表现；不新增实时毒伤条、随步数扣血或特殊同伴编队系统 |
| 如何恢复 | 普通治疗可恢复常规生命，但不解除剧情中毒事实；善后中的明确解毒节点才结束危机 |

**不用真实倒计时，也不用不可逆掉血制造紧迫感。** 玩家查任务、整理背包、离图再回来，不应导致伤者死亡。

### 3.2 金光表现与破解职责

| 顺序 | 表现 | 系统承担 |
|---|---|---|
| 初次展现 | 百眼张开肋下众目，金光使众人无法接近；撤退过程中伤者需要掩护 | 一次剧情演出，不启动必败战 |
| 尚未取得援助 | 再次交互提示必须先找克制之法 | 阶段条件检查，不靠高伤害、道具堆叠绕过 |
| 第一声啼鸣 | 金光散开，遮蔽消退，接近黄花观的条件恢复 | 固定剧情动作，保存“破光完成”事实 |
| 第二声啼鸣 | 百眼失去伪装，显出蜈蚣本相，无法再次合拢金光 | 固定剧情动作；不做音高、节奏或次数操作 |
| 此后交战 | 对付已失去金光庇护的普通单 Boss | `start2DBattle(enemies, onVictory, onDefeat)` |
| 战斗结束 | 昴日完成制伏或终结，众人取得解毒药并返回伤者处 | 胜利回调推进至善后，演出不重复 |

**因果必须清晰：不是打掉血条才破金光，而是昴日先破金光，玩家才有条件完成后续战斗。**

Boss 战败后，金光不复原、昴日不失约、玩家不重跑求援。

### 3.3 善后不能只剩领奖

建议顺序固定为：

**取得解毒药 → 伤者脱离危险 → 清点获救者 → 安排七女妖处置 → 清除丝洞危险 → 领取奖励。**

“烧盘丝洞”改为有条件的危险清除：

- 先撤空人员，核实无仍被缚住者。
- 焚除遗留毒丝、捕人设施等危险部分，不以报复性毁居作为爽点。
- 已投降或失去战斗能力的女妖必须先带离。
- 不把火光作为掩盖获救者去向与女妖处置的转场。

## 4. 是否需要 Boss 机制

### **不需要。**

| 判断项 | 结论 |
|---|---|
| 新章特色是否不足 | 不足不存在；蛛丝解缚、援助背叛、同伴中毒与啼鸣破光已经形成完整特色 |
| 是否复用时序车阵 | 不使用，避免把金光改造成等待窗口 |
| 是否复用姿态换甲 | 不使用，避免变成换眼色、切抗性的相似谜题 |
| 是否新增第三类机制 | 明确禁止；没有充分必要性 |
| 百眼战斗配置 | 普通单 Boss；现有直接攻击、毒类技能或同类基础技能分工即可 |
| 避免的变相新机制 | 千眼计数、逐眼击破、啼鸣冷却、金光充能、毒层阈值、特殊清毒物品循环 |
| 战斗长度 | 短于“寻援—破解”叙事所占比重，避免真正的破局被后续长战淹没 |

若现有战斗没有成熟毒状态，使用已有伤害技能配毒性描述即可，**不为本章临时新增持续中毒规则**。

### 最优先防住的四个问题

1. **ensure 写了却没接入**——必须通过真实地图加载路径验证，不能只直接调用方法测试。
2. **把战后对白当成推进开关**——对白被取消不应卡章。
3. **破光结果在战败后丢失**——不能让昴日援助变成反复跑腿。
4. **满包时提前清章或关闭 NPC**——结算入口必须持续可用，直到奖励状态与终态一致。
