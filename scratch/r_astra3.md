## 结论

采用 **“一轮亮阵 → 次轮喷火 → 两轮回气”** 的固定循环，并提供两条明确应对路线：

- **抢攻破阵**：蓄力回合集中攻击红孩儿，累计造成足够有效伤害，震坏当前阵眼车，取消本轮爆发。
- **防御守息**：蓄力回合执行防御，获得持续至爆发结算的减伤准备；无法阻止喷火，但能显著降低自身承伤，可配合用药稳住血线。

**五辆车只作为阵法表现，不新增战斗单位、不新增目标类型、不增加 Boss 血量。** 每轮仅一辆车显露阵眼，通过攻击红孩儿间接破坏。五行首先承担辨识和轮换作用，首版不追加五套元素克制规则。

## 一、阶段机设计

以下以蓄力回合为 **R**。完整循环为 **R 蓄力、R+1 爆发、R+2～R+3 恢复、R+4 再次蓄力**。

| 状态 | 进入条件 | 持续时间 | 对外可见信号 | 玩家应对 | 转移规则 |
|---|---|---|---|---|---|
| 待机 | 战斗初始化，尚未开放首次指令输入 | 不占战斗回合 | 五辆小车列阵，尚未点火 | 无需操作 | 初始化蓄力状态并展示预告，再开放第一轮输入 |
| 蓄力 | 首轮初始化；或恢复/破阵状态到期 | 完整一回合 R | 当前阵眼车高亮；Boss 显示“蓄火”；面板显示破阵进度及“下回合喷火”；日志写入相同信息 | 攻击/伤害技能累计破阵；防御获得守息；用药补血 | 达到破阵阈值立即进入破阵；否则回合末进入爆发待执行 |
| 爆发待执行 | 蓄力结束且未破阵 | R+1 内，直到 Boss 行动 | 五车通红，显示“本回合喷火”；未守息单位有危险描边 | 已守息单位可继续攻击或用药；临时防御只有赶在 Boss 前执行才生效 | Boss 行动执行一次三昧真火，转为爆发已执行 |
| 爆发已执行 | 喷火完成，或该次行动被既有规则取消 | R+1 剩余时间 | 已喷火则车轮熄暗；取消则提示“火势错过，阵火散去” | 按剩余行动正常操作 | 回合末进入恢复 |
| 恢复 | 爆发回合结束 | R+2、R+3 两回合 | 车轮暗淡，显示“回气 2/1”；Boss 只用普通攻击 | 输出、补血、调整资源 | R+3 回合末建立下一轮蓄力，R+4 开放输入前已可见 |
| 破阵 | R 内破阵进度达到阈值 | 立即生效，维持至 R+3 回合末 | 阵眼车出现裂纹；“阵破，本轮喷火取消”；其余车火焰熄灭 | 安全输出、恢复资源 | 期间 Boss 只用普通攻击；R+4 才重新蓄力 |

### 必须锁定的时序

**首次预告不能只放在 `executeRound` 开头。** 若此时玩家已经提交指令，提示再醒目也不算可应对。

- **首轮**：战斗初始化时写入蓄力 buff，通过已有 `message` / `buff` step 展示提示，之后才允许提交指令。
- **后续循环**：在上一轮的 `settleRoundBuffs()` 到期处理内建立蓄力 buff，播放预告；演出完成后，开放下一轮输入。
- **蓄力 R**：红孩儿该次行动固定为蓄火演出，**不额外造成伤害**，避免低速角色尚未应对就被惩罚。
- **爆发 R+1**：按现有速度队列行动；R 已建立的守息保护不依赖 R+1 的速度。
- **破阵不会提前启动下一轮蓄力**，否则玩家成功破阵反而导致爆发频率增加。

这里没有新增回合阶段，只是在**初始化、既有行动结算、既有回合末结算**中读写状态。

## 二、数据结构建议

### 1. 敌方单位字段

| 字段 | 建议内容 | 用途 |
|---|---|---|
| `mechanicId` | `five_element_cart` | 标识使用哪套局部机制规则 |
| `mechanicConfig` | 阈值比例、爆发倍率、守息倍率、恢复轮数、五行展示顺序 | 保存配置，不保存运行阶段 |

**不再额外挂 `phase`、`charging`、`broken` 等运行字段。** 运行状态统一放在 buff 中，避免字段与 buff 相互矛盾。

### 2. Boss 状态 buff

Boss 同时最多存在一条 `hh_cart_state`。

| 字段 | 内容与约束 |
|---|---|
| `id` | `hh_cart_state` |
| `name` | 随状态显示“车阵蓄火 / 五车俱燃 / 回气 / 阵眼已破” |
| `phase` | `charge / burst / recovery / broken` |
| `duration` | 距离该状态到期还需经过的回合末次数 |
| `appliedRound` | **真实写入回合**，不伪造为未来回合 |
| `activeFromRound` | 允许 AI 使用该状态的起始回合；处理“上一轮末写入、下一轮生效” |
| `cycleStartRound` | 本轮蓄力回合 R |
| `cycleId` | 来源 Boss ID 与 R 组成的稳定标识 |
| `eyeElement` | 本轮阵眼所属五行；按固定顺序轮换 |
| `breakProgress` | 本轮已累计有效伤害 |
| `breakThreshold` | 本轮固定阈值，开始蓄力时确定 |
| `resolved` | 爆发是否已执行或已取消，防止重复结算 |

### 3. 玩家守息 buff

| 字段 | 内容与约束 |
|---|---|
| `id` | `hh_cart_guard` |
| `name` | 守息避火 |
| `sourceId` / `cycleId` | 精确绑定施法 Boss 和本轮阵法 |
| `appliedRound` | 实际防御动作执行的回合 |
| `duration` | R 获得时为 2，R+1 获得时为 1 |
| `burstDamageFactor` | 建议 `0.65`，只作用于对应车阵爆发 |
| `consumed` | 爆发伤害结算时消耗一次 |

**守息是防御动作得到的机制准备，不是把普通防御永久延长。** R+1 改选攻击不会清除它；破阵、喷火完成、该轮喷火取消或战斗结束时清除。

### 4. 与回合末递减的衔接

`settleRoundBuffs()` 内采用明确顺序：

1. 按现有规则结算 DOT。
2. 递减本次结算开始时已有的 buff。
3. 移除到期状态，并完成该机制的状态替换。
4. **替换出来的新 buff 不在同一次结算中再减一次。**

例如，R 回合末创建的爆发状态记 `appliedRound=R`、`activeFromRound=R+1`、`duration=1`，到 R+1 回合末才到期。

只需要局部状态到期处理，**不引入新的顶层事件系统，也不在 `executeRound` 中散布阶段分支**。AI 将状态映射为现有 `{ type: 'skill', skill, targetId }` 或普通攻击即可。

## 三、应对判定规则

### 建议初始数值

| 参数 | 首版建议 |
|---|---|
| 破阵阈值 | Boss 最大生命的 5%，当前为 **2100** |
| 完整车阵爆发 | 既有普通火系法术基准伤害的 **1.5 倍**，对存活玩家单位逐个结算 |
| 守息减伤 | 对本轮车阵爆发减伤 **35%** |
| 恢复期 | 固定 2 回合，只使用普通攻击 |
| 额外灼烧 | 首版不添加，避免失败惩罚叠加不透明 |

2100 是起测值；验收目标是**正常进度队伍需要有意识地集中输出才能达到，而非随便一击或必须全员暴击**。调整阈值优先于提高 Boss 属性。

### 布尔判定表

| 玩家行为 | 生效条件：全部满足才为真 | 阵法响应 |
|---|---|---|
| 普通攻击累计破阵 | `处于蓄力期` 且 `目标为红孩儿` 且 `来源为玩家主动攻击` 且 `实际扣血 > 0` | 实际扣血加入破阵进度 |
| 伤害技能累计破阵 | `处于蓄力期` 且 `技能对红孩儿实际扣血 > 0` | 与普攻等价；多段逐段累计 |
| 成功破阵 | `处于蓄力期` 且 `累计进度 ≥ 本轮阈值` 且 `本轮尚未破阵` | 立即进入破阵，取消本轮喷火，清除对应守息 buff，反馈只触发一次 |
| 防御获得守息 | `防御动作实际执行成功` 且 `处于蓄力或未执行的爆发期` | 对执行者赋予/刷新本轮守息，不叠加层数 |
| 守息减伤 | `本次伤害为车阵爆发` 且 `sourceId、cycleId 匹配` 且 `守息尚未消耗` | 应用减伤并消耗 |
| 用药 | `按既有物品规则成功使用` | 正常回血/回蓝，不削减破阵阈值、不自动解除阵法 |
| 水系技能 | `满足普通伤害技能累计条件` | 可以靠有效伤害震破阵眼，**不能仅凭“水系”标签熄灭真火** |
| 招降 / 逃跑 | `既有规则判定成功` | 正常结束战斗并清理机制；失败不视为已经应对 |

补充边界：

- DOT、反伤、反击不累计破阵，避免上一轮自动伤害无操作解阵。
- 闪避、零伤害不累计；溢出进度只显示到阈值。
- 进入 R+1 后破阵窗口关闭，不能在看到喷火后再用累计伤害追溯取消。
- 队员可以分工：部分角色破阵，危险角色守息，**不要求全队统一选择唯一答案**。
- 车阵准备技和爆发技都必须在实际执行时复查状态，避免 AI 已预选蓄火、玩家先破阵后，红孩儿又把阵法点起来。

## 四、伤害与减伤

### 结论：复用通用法术结算，不使用物理攻击公式硬套，也不另写完整伤害公式

`calculateAttackDamage()` 已给出的接口只证明它支持攻击计算与测试注入，**不能据此假定它完整支持法术抗性**。

车阵爆发应作为一个专属法术技能：

> 沿用现有普通火系法术的基础计算，仅调整威力倍率与目标范围；其余命中、抗性、防御及最终扣血规则保持现状。

| 环节 | 规则 |
|---|---|
| 威力输入 | 在既有法术威力输入处应用 1.5 倍，不在最终伤害上再次乘算 |
| 命中、暴击、波动 | 沿用该法术管线；测试固定随机源。不因为是 Boss 机制就强制必中、暴击或致命 |
| 法术防御与火抗 | 保留现有结算；若当前没有独立火抗字段，不凭空新增一套 |
| 普通防御与守息 | 在防御减伤所在位置计算，**同类取更强，不重复相乘** |
| 变身减伤 | 保持 `法力抵扣 → 逆御免伤 → 画皮移伤` 原顺序，每个目标一次 |
| 最终扣血 | 沿用现有取整、最低伤害、死亡检查及演出规则，不新增“必掉血”下限 |

例如，普通防御留下 50% 伤害、守息留下 65% 时，采用 **50%**，不是 `50% × 65%`。

**防御本身不能无伤，但允许既有免伤或法力资源把伤害进一步挡住。** 不为了展示机制而绕过玩家已有构筑。

### 数值验收标准

- 满血、正常进度角色不应被无暴击爆发普遍秒杀。
- 守息应显著改善存活率，但低血线角色仍需要用药。
- 未应对造成清晰的群体血线压力，不再附带强制失明、破防、灼烧等连环惩罚。
- 破阵后强度通过**取消爆发、限定普通攻击**下降，不靠修改 Boss 基础攻击属性，避免恢复时漏还数值。

## 五、提示与失败反馈

### 提示内容必须包含操作信息

蓄力提示建议固定为：

> **五行车阵蓄火：下回合喷火。本回合对红孩儿造成 2100 点有效伤害可破阵；执行防御可守息，降低本轮喷火伤害 35%。**

视觉同时展示：

- 五辆车及高亮阵眼，配五行文字标识，不只靠颜色辨认。
- “破阵进度 860 / 2100”。
- “下回合喷火”倒计时。
- 守息角色头顶盾形标识及“守息”文字。

日志通过已有 `message`，状态通过 `buff`，爆发通过 `cast` 与现有伤害 step 表达，**不新增 step 类型**。

### 四句战报文案

| 场景 | 文案 |
|---|---|
| 蓄力预告 | 红孩儿：“五车归位！下一轮，叫你们连骨头也烧酥了！” |
| 成功破阵 | 悟空：“嘿！火浇不灭，俺老孙还砸不得你这车架？”【阵眼已破，本轮喷火取消】 |
| 未破阵爆发 | 红孩儿：“阵眼还在，你们就一个也别想躲！”【破阵失败：有效伤害 1480 / 2100；五车齐燃】 |
| 守息生效 | 悟空：“莫张口！守住气，才不吃这烟火的亏！”【守息减伤 35%；实际承伤见伤害记录】 |

爆发日志还应逐目标标明“守息已生效”或“未守息”，并显示最终伤害。未破阵但已守息属于**另一条应对路线成功**，不要统一记成“玩家应对失败”。

## 六、Node 测试断言清单

| # | 断言意图 |
|---|---|
| 1 | **预告先于输入**：首轮及后续循环的预告 step 均在玩家可提交该轮指令前产生；包含爆发回合、阈值和防御效果。界面层另验车阵及进度可见。 |
| 2 | **阶段确定性**：固定随机数、不干预时，严格经历 R 蓄力、R+1 爆发、R+2～R+3 恢复、R+4 再蓄力；无随机跳阶段。 |
| 3 | **抢攻破阵生效**：普攻与伤害技能累计达到 2100 时只触发一次破阵；R+1 不产生爆发伤害，多段技能后续命中不重复奖励。 |
| 4 | **累计边界正确**：2099 不破阵，2100 破阵；强制闪避、零伤害、DOT、反伤、反击不计入；水系有效伤害可累计但不自动熄火。 |
| 5 | **低速守息有效**：低速角色在 R 执行防御，R+1 即使晚于 Boss 行动、或改选攻击，守息仍正确减伤且不自动无伤。 |
| 6 | **守息不叠乘**：重复防御不增加层数；普通防御更强时采用普通防御；来源或轮次不匹配的守息不影响本次伤害。 |
| 7 | **未应对后果可归因**：不破阵且不防御时只爆发一次；战报含最终破阵进度、爆发技能、未守息标记和实际伤害。 |
| 8 | **减伤链一致**：同一基础伤害下，法术防御、现有抗性及普通防御照常生效；法力抵扣、逆御、画皮依次调用且各一次，不绕过、不重复。 |
| 9 | **破阵后强度回落**：破阵后至 R+3 只使用普通攻击；不会提前重新蓄力，不永久改动原始攻击或法术攻击属性。 |
| 10 | **到期无多减/漏清**：R 回合末新建的爆发 buff 不被当场递减；喷火、破阵、到期后清除对应守息；Boss 不同时持有两个阶段状态。 |
| 11 | **队列与结束边界安全**：预选准备技后被破阵不会重建车阵；Boss 死亡、战斗结束后不喷火；若既有行动限制取消喷火，本轮不顺延补发。 |
| 12 | **读档无残留、基线不回退**：非战斗存档恢复和重新开战不携带车阵/守息；若支持战斗中存档则精确恢复当前轮次与状态，不重复预告或喷火；新增用例及原 1847 条全部通过。 |

**首版实现边界：固定循环、单阵眼累计破阵、跨轮守息、既有法术减伤链。先把“看得见、来得及、有选择、能归因”做完整，再考虑五行差异。**
