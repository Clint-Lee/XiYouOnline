## 结论

**采用“七阶段、一次正式首领战、不新增 Boss 机制”的方案。**

- 先明确表态 **“祭童的事今日为止”**，再完成孩子安置与替身准备，禁止直接进入战斗。
- 祭坛现身、冰封劫人采用剧情演出；正式战斗放在水府，目标是**救人、逼退灵感大王**，不是击杀。
- 观音收妖、安抚受害者必须完整落地；奖励成功领取后完成渡河，闭环至 `tongtian_cleared`。
- 复用现有对白、线索选项、阶段表、奖励与战斗接口；**不增加护送系统、献祭倒计时、儿童血条或第三套 Boss 状态机。**

## 3. 献祭事件的叙事结构

### 3.1 核心流程

| 节点 | 呈现方式 | 玩家行为与叙事作用 |
|---|---|---|
| 看见代价 | 陈家长者解释轮到谁；孩子紧抓家长，不敢往门外走；家长不是认可献祭，而是长期受胁迫 | 先理解要保护的具体人物，而不是领取一个“打怪任务” |
| 明确表态 | 必选推进句：“**祭童的事今日为止。孩子留下，我们去见那妖怪。**” | 将“不再让孩子承担风险”确立为行动前提 |
| 允许追问 | 可询问河神来历、往年情形；追问后回到表态节点 | 不提供“继续献祭换取除妖机会”的假分支；暂不接受就不推进 |
| 安置孩子 | 明确说清孩子留在哪里、由谁陪护；长者与家长确认 | 保护不是一句口号，先落实再出发 |
| 准备替身 | 悟空与八戒变作两名孩子的模样；从孩子视角之外呈现变身 | 由有能力的成年人承担诱敌风险，不要求儿童充当诱饵 |
| 妖怪现身 | 河风骤停、祭灯变冷、黑水向岸边抬升；妖怪以索取祭童的口吻发问 | 以环境和强制秩序制造压迫，不描写进食细节 |
| 计划遇挫 | 替身被识破，妖怪封冻近岸、转袭留守处；八戒返身护师时同唐僧被掳，悟空护住撤离中的村民 | 敌人的报复不否定救孩子的选择，也不把灾难归咎于孩子 |
| 救人与伏法 | 水府战先救人；观音随后收妖，明确停止献祭，认真安抚家长与孩子 | 区分“打赢一次”“终止威胁”“修复安全感”三个结果 |

### 3.2 幽默边界

**本版建议不使用幽默。**

因为首次接案已经见到孩子，后续再安排八戒“太胖装不像”的笑话，会越过“一旦见到孩子立刻收住”的界线。允许的幽默位不是必须使用的配额。

### 3.3 线索选项

水府入口复用既有固定题模式：

- 观察内容同时提供两条证据，例如**气泡连续从未冻结的暗流口上浮，主门冰层则向外吐出寒气**。
- 正确选择：循暗流侧口进入。
- 错误选择：正撞冰封主门。
- 错答通过 `nextStep` 返回原观察步骤；**不扣血、不消耗道具、不降阶段、不随机换题**。
- 正确选项仍需检查地图、阶段及战斗锁，不能仅凭对白 action 无条件开战。

### 3.4 为什么比直接开打更有分量

**真正的选择是“先承担保护责任，再追求战斗胜利”，而不是让玩家在牺牲孩子与拿奖励之间二选一。**

孩子先被留下，玩家的表态就改变了事件；替身行动让承诺转化为风险；水府救援和最终安抚则检验了承诺是否兑现。直接开打只能证明角色强，这套结构还能证明他们为何而战。

## 4. 灵感大王是否需要新 Boss 机制

### 判断：不需要，普通首领战足够

| 判断维度 | 结论 |
|---|---|
| 本章核心 | 重点是终止献祭、承担替身风险、救人与安抚，不是第三次机制教学 |
| 与前两章区分 | 不做“寒气蓄力→爆发→恢复”，避免换皮五行车阵；不做“冰甲/水形切换”，避免换皮黑水换甲 |
| 首领身份 | 通过出场、寒冰表现、攻击文案和战后退走体现，不必依赖新状态机 |
| 实施风险 | 新增冻结资源、溺水条、救援倒计时，都会扩大状态、失败恢复与断言成本 |
| 战斗结束语义 | 胜利代表破开防线、救出唐僧八戒、逼其退回深水；最终收妖留给观音 |

### 战斗执行约束

| 项目 | 方案 |
|---|---|
| 战斗入口 | 仅 `tongtian_rescue` 的水府线索正确选项可调用 `start2DBattle` |
| 敌人配置 | 以项目已有完整 Boss 对象为模板，逐字段补齐；不要只提供名称、血量和攻击 |
| 招式表现 | 采用既有伤害结算；水击、寒流只作表现区分。若已有成熟减速技能可复用，否则不新增冻结控制 |
| 状态与 buff | 不新增 `hh_*` 或 `tongtian_*` 专属机制 buff，不改写基础属性 |
| 队伍一致性 | 被掳角色不得在战斗表现中正常参战；使用现有队伍能力实现，不另做队伍系统 |
| 失败 | 留在救援阶段，按既有败战规则恢复到可交互入口，允许重试，不再次播放劫人 |
| 胜利 | 先写入新阶段，再调度战后对白；避免重复胜利回调重复推进 |
| 奖励归属 | 战斗不发本章终章奖励；终章奖励统一走陈家长者，避免两条结算路径 |

**战斗与叙事一致性须前置核查：**若现有战斗器无法排除被掳伙伴，应先确认可复用的单人战/临时出战配置，不能让唐僧、八戒一边被关、一边正常参战。
